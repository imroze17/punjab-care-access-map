## Approved deviations from the handoff

1. **Focus ring stays blue** (§9.1 proposed green). A green ring measures 1.57:1
   against the green primary button. Blue measures 9.96:1 on white, 9.06:1 on the
   page canvas, 8.19:1 on its own halo. Owner approved.
2. **Project title set to `--text-title` (26–30px)** per §8.3 even though §5.1 asks
   for a compact header. The header grew from 77px to 93px. Revisit in Phase 2 if
   it pushes the first task too far down on short viewports.
3. **Summary strip kept at three metrics** rather than being replaced outright.
   §5.5 permits a modest results summary; it is now an inline strip, not KPI cards.
   The honest "entries with a listed telephone number" metric (13 of 112) is a
   Phase 2 content change.
4. **Inter is still not self-hosted.** Declared in `--font-ui` with a system
   fallback. `document.fonts.size === 0` — visitors without Inter installed get
   `ui-sans-serif`. §8.1 self-hosting is scheduled for Phase 3 ("approved font
   assets"), and the CSP `default-src 'self'` means no external font request can
   be added without shipping the files.

## Known limitations carried forward

- Map district labels are overlapped by district-group count markers at the
  default extent. Pre-existing; Phase 2 (§12.4).
- The two-column split is cramped between 721–900px (map panel ≈370px). The
  single-column breakpoint is still 720px. Phase 2 (§6.2, §7.1).
- Ownership filter "all pressed = no filter" ambiguity is unchanged (UX-03).
- Legend still advertises rivers when the river layer is off (UX-09).
- Correction route remains unavailable: `correctionRoute` is `null` and §13.3
  forbids inventing one.
- No Panjabi/Gurmukhi interface text. `publishedLocales` is `["en"]`, enforced.
- `--font-pa` is declared but unused and untested; no native-reader review.

## Rollback

Phase 1 is additive and confined to the style layer plus one JS line.

```bash
# Revert the whole phase, keeping the baseline audit notes:
git revert --no-commit <phase1-merge-sha>
git checkout HEAD -- design/
make check
```

To drop only the token layer without reverting the rest, remove the
`--tokens-style` default from `scripts/build_p0.py`, delete the
`check_phase1_visual_tokens` call in `scripts/validate_p0.py`, and rebuild — the
legacy aliases at the foot of `src/tokens.css` are what the older rules consumed,
so removing the file alone will leave variables undefined.
